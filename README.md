# NurAgent

**NurAgent** — кооперативный AI-проект на базе Telegram и web-технологий.

Цель проекта — создать полезного AI-агента для обучения, мышления и поддержки,
а также прозрачную партнёрскую модель участия.

---

## 🤝 Партнёрская модель

Все средства, полученные проектом, распределяются по следующей схеме:

- **70%** — распределяется поровну между активными партнёрами проекта
- **10%** — направляется на новые инвестиционные проекты
